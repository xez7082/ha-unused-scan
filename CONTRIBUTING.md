# Contribuer

Merci de votre aide ! Les contributions sont les bienvenues (corrections, idées, traductions).

- Signalez un bug ou proposez une idée via les *Issues* (modèles fournis).
- Pour une modification de code : ouvrez une *Pull request* avec une courte description et le résultat de vos essais.
- Le module n'utilise que la bibliothèque standard Python : merci de ne pas ajouter de dépendance.
- **Règle d'or : ne jamais supprimer** de fichier de l'utilisateur. Tout doit rester réversible (archivage).
- Interface : texte de 14 px minimum, boutons de 48 px minimum, contraste élevé.

Test local : `HA_CONFIG=/chemin/vers/config DEV=1 PORT=8123 python3 ha_unused_scan/app/server.py`
puis ouvrir http://localhost:8123.
