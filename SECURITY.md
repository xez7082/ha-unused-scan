# Sécurité

Le module n'est joignable que via Home Assistant (Ingress) et réservé aux administrateurs.
Il écrit uniquement dans `packages/`, `automations.yaml` et `_archive/`, et n'a aucun accès réseau externe.

Pour signaler une faille, ouvrez un *Security advisory* privé dans l'onglet **Security** du dépôt
(ne la publiez pas dans une Issue publique).
